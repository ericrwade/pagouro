## The one-paragraph state

Two finished, frozen, public artefacts exist. **Pagouro 1.0** (the 1B text model on a USB stick; released
2026-09-29) and **Pagouro BE 1.0** (the Belle Époque poster image model, same rules, same key; released the
same evening). Nothing is running, nothing is rented, nothing is owed, no maintenance is promised. Every
claim either makes is a number measured on a frozen test that ships with it, and every receipt (manifest,
signature, Bitcoin timestamp, Arweave/QStorage copies) is public. **There is no v1.1 planned.** Changing a
shipped byte would require re-signing, re-timestamping and a new release; the honest path for any change is
a new version or a fork, never an edit of 1.0.

## Known rough edges (recorded, deliberately not "fixed")

- Pagouro E1–E4 (`docs/ERRATA_v1.0.md`): the stick's verifier looks for `minisign.pub` (ships as
  `pagouro.pub`), CHECK_YOUR_COPY names the same file, the zip has backslash paths (PowerShell 5.1), the app
  banner says 0.1.0. Workarounds are on the errata page. Fixing them means a new version.
- Pagouro BE: the q8_0 quantisation of the shipped checkpoint draws blank images on CPU, cause undiagnosed;
  the f16 file ships (2.58 GB). It adds unreadable lettering to ~85 % of pictures; the box says so.
- arweave.net had not served the 1.76 GB Pagouro zip by 2026-09-30 (HTTP 572; the small files it serves);
  the zip is byte-verified from turbo-gateway.com. Re-check only if someone asks.
