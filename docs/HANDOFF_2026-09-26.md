## 5. Lessons from this window (already in `~/.claude/CLAUDE.md` or to add)

- A single-turn eval cannot see multi-turn failures; the 4-turn smoke is part of every measurement.
- A GRPO curriculum with one prompt style saturates; build it from the policy's own failures across every category
  the frozen test has (this is what round 4 does).
- A detached `setsid nohup … &` inside an ssh one-liner can hold the ssh session open for hours; wrap it in
  `( … & )` so the launcher returns.
- The desk's internet can die mid-transfer: verify every upload by hash and never assume a chain started.
