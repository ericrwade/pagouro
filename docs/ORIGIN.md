# Where Pagouro came from

Pagouro began as a question: could one person, with no GPU, build a language model from scratch
and run it as a plain executable? The first idea was narrow, a small model trained on a
cryptocurrency forum. Talking it through turned it into something else: a standalone,
fully documented framework for a model that lives on a USB stick, runs offline on any machine,
and needs nothing from outside.

Three commitments came out of that conversation and have not moved since. Every byte of training
data has a named license and a row in a public ledger. The model is trained to say "I don't know"
rather than invent an answer, and that claim is measured and published, not asserted. And nothing
the user types ever leaves their machine.

The name is the Greek *págouros*, hermit crab: an animal that carries a home it did not build and
can move out of. The *ouro* nods to ouroboros, the loop that needs nothing from outside.

It is released as a finished artifact, fully open, with no maintenance promise. It is meant to be
a working minimum that someone with time, skills, or money can make bigger: every script, every
decision, and every mistake is in the repository so the next person starts where this one stopped.
